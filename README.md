# GitHub User Activity

A command-line interface (CLI) tool that fetches and displays the recent activity of any GitHub user. Built entirely with Python's standard library (no external dependencies required).

**Project Page:** [https://github.com/Punxxet/GitHub_User_Activity](https://github.com/Punxxet/GitHub_User_Activity)

## Features
- Fetches real-time event data using the GitHub API.
- Formats common events (Pushes, Pull Requests, Repository Creation, Forks) into readable text.
- Includes robust network error handling, rate-limit detection, and timeout protection.

## Prerequisites
- Python 3.x
